/**

## 三、后端描述语生成规则（供前端同学理解数据来源）

以下文案全部由后端 `if-else` 规则生成，前端无需处理逻辑，**直接展示 `summary` 字段即可**。

### 睡眠分析 summary

| 条件 | 输出文案 |
|------|---------|
| `totalSleepHours > 7` | "昨晚睡得不错，时长充足" |
| `totalSleepHours < 5` | "昨晚睡眠偏少，建议白天小憩" |
| `5 ≤ totalSleepHours ≤ 7` | "昨晚睡眠时长一般" |
| `deepSleepPercent > 40` | 追加 "深度睡眠质量较高" |
| 无数据 | "暂无近7天睡眠数据，请佩戴睡眠监测设备" |

### 陪伴记录 summary

| 条件 | 输出文案 |
|------|---------|
| 有负面情绪（低落/焦虑/担忧/着急/孤单/疲惫/思念） | "近期情绪有波动，建议多视频通话" |
| 正面情绪占比 ≥ 60%，且无负面 | "最近情绪稳定，状态良好" |
| 其他 | "情绪状态有待关注，建议多加陪伴" |

### 音乐疗法 summary

| 条件 | 输出文案 |
|------|---------|
| 近7天有播放记录 | "近期有听音乐放松，继续保持" |
| 近7天无播放记录 | "近一周未使用音乐疗法，可尝试播放助眠白噪音" |

### 物品寻找

无 summary 字段，只返回最近5条记录。
