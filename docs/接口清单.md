## 一、通用约定

- **统一响应包装**：后端返回 `{ "code": 200, "message": "success", "data": ... }`。前端 `apiFetch()`（js/mock-data.js:221）严格以 `code === 200` 判定成功，并自动解包返回 `data`；非 200 弹 Toast 并返回 `null`。
- **请求头**：`Content-Type: application/json`；若 `localStorage.access_token` 存在，自动附带 `Authorization: Bearer <token>`（注：后端手册未定义鉴权机制，登录返回的 token 当前为 `null`）。
- **超时**：默认 10 秒（`REQUEST_TIMEOUT`），超时/网络错误统一 Toast 提示并返回 `null`。
- **分页约定**：Query 参数 `page`（默认 1）、`pageSize`（默认 20）；返回 `data: { list: [], total, page, pageSize }`（前端兼容 `list / records / data` 三种字段名及纯数组）。
- **模式开关**：`config.js` 中 `USE_MOCK: false` 表示调用真实后端；为 `true` 时使用本地 Mock 数据。部分列表接口（老人/告警/工单）在请求失败时会回退到本地缓存数据兜底。
- **页面轮询**：dashboard / alerts / elderly 页面按 `POLLING_INTERVAL`（5000ms）定时刷新列表数据。

## 二、认证模块（index.html 登录/注册页）

### 2.1 社区端登录 ✅
- **接口名称**：社区管理端登录
- **功能描述**：工作人员使用手机号 + 密码登录，成功后前端保存 `current_staff`、`is_logged_in` 并跳转 dashboard.html
- **请求方式**：POST
- **请求路径**：`/api/auth/login/web`
- **请求参数**（Body JSON）：`phone` string 必填（手机号）；`password` string 必填
- **返回数据**：`data`：`userId` string、`name` string、`phone` string、`role` string（admin/supervisor/staff）、`userType` string（"staff"）、`token` string（当前为 null）、`avatar` string?（可能不含，前端会再调 2.4 补拉）、`refreshToken` string?
- **前端函数**：`login(phone, password)`（index.html:72）



### 2.3 用户注册 ✅
- **接口名称**：注册账号
- **功能描述**：注册新用户，社区端注册页固定以 `userType="staff"` 提交，name 传手机号
- **请求方式**：POST
- **请求路径**：`/api/auth/register`
- **请求参数**（Body JSON）：`phone` string 必填；`password` string 必填（≥6 位）；`name` string 可选；`userType` string 必填（staff/family）
- **返回数据**：按统一包装返回（手册未给出具体 data 结构 ?）
- **前端函数**：`registerUser()`（index.html:99）

### 2.4 获取当前用户信息 ✅
- **接口名称**：查询用户信息（auth/me）
- **功能描述**：登录成功后补充拉取用户头像等资料；顶栏头像自动刷新也调用此接口
- **请求方式**：GET
- **请求路径**：`/api/auth/me`
- **请求参数**（Query）：`phone` string 必填
- **返回数据**：用户信息对象（字段可参考 LoginResponse：`userId/name/phone/role/userType/avatar` 等，手册未详述 ?）
- **前端函数**：`getAuthMe(phone)`（登录流程、js/utils.js:229）



### 2.6 退出登录 ✅
- **接口名称**：退出登录
- **功能描述**：顶栏"退出登录"调用，随后前端清理 localStorage 并跳回 index.html（接口失败也会强制本地登出）
- **请求方式**：POST
- **请求路径**：`/api/auth/logout`
- **请求参数**：无
- **返回数据**：按统一包装，无 data
- **前端函数**：`logoutApi()`（js/utils.js:303 `logout()`）
