## 第二部分：进阶难度（7–21）

### A. 告警链路与设备状态

7. 从设备发生跌倒告警，一直到 App 弹出告警提醒，请完整描述整条端到端链路以及每段使用的通信协议。
8. 项目如何判断设备在线、离线？是否实现完整的设备离线告警功能？
9. 边缘网关网络断开离线之后，整套系统会出现哪些现象？网关网络恢复之后数据如何处理？

### B. 通信协议与报文处理

10. MQTT 中后端是发布者还是订阅者？EMQX MQTT Broker 部署在哪里？后端订阅了哪些 MQTT 主题？
11. MQTT 消息格式错误、字段缺失的时候，后端会如何处理？
12. 后端接收边缘网关上报的 HTTP 报文，如何解决网络重传带来的重复上报问题？

### C. 后端分层与调用链

13. 后端 Controller-Service-Repository 标准调用流程是什么，请举业务例子说明。
14. Service 层之间是否存在互相调用？某个 Service 出现异常故障，会对其他业务模块产生什么影响？

### D. 启动流程与运行表现

15. 后端启动完整流程是什么？启动日志中需要重点关注哪些关键信息？
16. 后端启动阶段，如果 MySQL 没有启动、EMQX 没有启动，后端分别是什么运行表现，为什么这么设计？

### E. 数据处理与业务一致性

17. 传感器上报异常体征数据，后端如何处理这些异常值，是直接丢弃还是保留？
18. 告警记录和通知记录同时写入数据库，如果通知写入失败，当前代码会出现什么现象？该如何改进？
19. 工单有哪几种创建方式？工单完整状态流转是什么样的？工单完成之后告警状态会不会自动同步更新？
20. 当前项目没有集成 Redis，请说明计划引入 Redis 用来解决哪些业务问题？引入 Redis 之后数据读写链路会发生什么变化？
21. 文件图片存储在服务器本地磁盘，磁盘占满时后端上传会发生什么？本地存储存在哪些弊端？

## 第三部分：深度拔高难度（22–51）

### A. 性能与数据存储

22. 设备上报数据后端是单条实时写入 MySQL，还是批量写入？大量设备并发接入会产生什么瓶颈，有哪些优化手段？
23. 后端 QPS 大概多少，系统主要性能瓶颈点有哪些？
24. 老人数量上涨到 1000 人，从数据库、连接池、缓存、MQTT、应用实例、服务器硬件层面分别给出扩容方案。
25. sensor_data 传感器数据表随着时间持续膨胀，会带来什么性能问题？分表、冷热归档如何落地实现？
26. 后端数据库表之间的 ER 关系是什么？哪些表是系统的性能瓶颈表？
27. 数据库告警与通知写入没有事务，会出现什么数据一致性问题？
28. 如果后续接入 Redis，如何保证 Redis 与 MySQL 之间的数据一致性？Redis 崩溃之后系统还能不能正常工作？
29. 项目文件存储有没有按日期分目录？文件命名如何保证唯一性，有无自动文件清理策略？
30. 网关上传图片元数据存放在哪张数据表，图片查询条件、URL 如何构成？
31. 后端数据库是否做备份，备份策略是什么？

### B. MQTT 与消息可靠性

32. 告警消息可靠性依靠哪些机制？MQTT QoS 1 起到什么作用？哪些场景下依然会出现消息丢失？
33. MQTT 协议 QoS0、QoS1、QoS2 分别代表什么含义，本项目选用的是哪一级，为什么没有全部使用 QoS2？
34. MQTT 消息生产速度大于消费速度，消息堆积会造成什么后果？可以采用哪些缓解手段？
35. 当前告警处理是同步执行业务逻辑，如果不引入消息队列会有什么风险？如果引入 Kafka，告警链路该如何改造？
36. 云端后端实例宕机重启，MQTT 消息是否会丢失，取决于哪些 Broker 配置？

### C. 故障与高可用

37. 分别说明感知硬件故障、边缘网关故障、EMQX 故障、MySQL 故障、SpringBoot 后端服务故障，各自的故障影响范围。
38. 数据库连接断开、MQTT 连接断开后端分别是什么行为，是否具备自动重试能力？
39. 告警处理流程中，如果数据库写入失败、通知处理失败，后端如何处理，告警是否会重试？

### D. 架构与设计决策

40. 本系统哪些业务属于边缘计算，哪些业务属于云计算？边缘与云端的任务划分依据是什么？
41. 对比「边缘网关中转架构」和「设备直连云端 MQTT 架构」，两种架构的优缺点？
42. 为什么后端选用 Java Spring Boot，而不选择 Python、Node.js 技术栈？
43. 为什么选用 MySQL 存储业务数据，暂不接入 Redis？MQTT 与 HTTP 双协议搭配使用的理由是什么？

### E. 安全防护

44. 边缘网关上报接口依靠 upload_id 实现幂等，如果 upload_id 被恶意伪造，会产生什么安全风险，如何防护？
45. 项目做了哪些安全防护？接口鉴权现状，存在哪些安全漏洞，后续如何加固？

### F. 监控与运维

46. 后端是否存在健康检查接口，可以检测哪些组件状态？
47. 后端健康检查接口目前只检测数据库连通性，还可以扩展哪些监控指标？
48. 后端日志存储在哪里？线上排查问题如何定位错误？是否配置异常告警能力？
49. Nginx 反向代理在本项目中承担了哪些职责？

### G. AI 模块
